# Jojo Brownfield Docs

This folder captures the working knowledge needed to change the existing Jojo BoxLang/ColdBox app safely.

Planning documents:

- `PRODUCT_REQUIREMENTS.md`: inferred product definition, actors, prioritized functional and nonfunctional requirements, acceptance criteria, and decisions needing confirmation.
- `PROJECT_SCOPE.md`: production-baseline boundaries, delivery phases, dependencies, risks, deliverables, and definition of done.
- `ARCHITECTURE.md`: current and proposed architecture, component/data/security/deployment design, route permissions, and architecture decisions.

Maintenance and assessment documents:

- `BROWNFIELD_CODE_COMPREHENSION.md`: architecture map, request flows, ownership boundaries, and change patterns.
- `REFACTORING_ROADMAP.md`: staged refactoring plan with safety gates and test expectations.
- `SECURITY_REVIEW.md`: current threat model, observed controls, risks, and hardening backlog.
- `DOCUMENTATION_GUIDE.md`: documentation conventions and checklists for future changes.
